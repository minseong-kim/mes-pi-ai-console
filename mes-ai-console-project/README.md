# MES AI Console — Bilingual Offline Front-End Demo

## 실행 방법
1. ZIP 압축을 해제합니다.
2. 최상위 폴더의 `index.html`을 더블클릭합니다.
3. English 또는 한국어를 선택합니다.
4. 폴더 구조를 변경하지 마십시오.

## 폴더 구조
```text
MES_AI_Bilingual_Launcher/
├─ index.html
└─ mes-ai-console-project/
   ├─ README.md
   ├─ pages/
   │  ├─ MES_Console_Full_EN (8).html
   │  └─ MES_Console_Full_KR (24).html
   └─ assets/
      ├─ css/launcher.css
      └─ js/launcher.js
```
